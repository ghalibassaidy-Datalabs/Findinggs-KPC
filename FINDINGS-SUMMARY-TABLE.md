# KPC App Backend — Security Findings Summary Table

> **Audit Date**: May 18, 2026  
> **Status**: All Open — Remediation Required

| No  | Priority   | Findings                                                                            | Location                                                                                                                    | Risiko Konkret                                                                                                                                                                          | Rekomendasi Fix                                                                                                                                                                             |
| --- | ---------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **HIGH**   | CORS dikonfigurasi dengan wildcard (`*`) dan `credentials=True`                     | `app/core/config.py` · `app/main.py` · `CORSMiddleware`                                                                     | Semua website di internet dapat mengakses API dengan identitas user yang sedang login. Melanggar CORS spec — browser modern menolak wildcard + credentials.                             | Set `CORS_ORIGINS` ke domain spesifik (misal `https://app.kpc.co.id`). Tambahkan startup validator yang block jika nilai masih `*` di environment non-development.                          |
| 2   | **HIGH**   | API Docs Production Open Public                                                     | `app/main.py` · `https://api.genai.kpc.co.id/docs#/`                                                                        | Siapapun dapat mengakses endpoint UI Swagger dan dapat melihat semua endpoint beserta body request-nya, termasuk Azure AD client ID.                                                    | Implementasikan hide API Docs di Production: set `docs_url=None` dan `redoc_url=None` jika `ENVIRONMENT=production`.                                                                        |
| 3   | **HIGH**   | PKCE State disimpan di in-memory dict Python                                        | `app/api/v1/auth.py` · variabel `auth_states: Dict`                                                                         | Login gagal saat multi-instance deployment atau restart; memory leak dari state yang tidak pernah dihapus; tidak scalable di Cloud Run dengan multiple instances.                       | Migrasi state ke Redis atau database dengan expiry timestamp. Implementasikan background cleanup task untuk state kedaluwarsa.                                                              |
| 4   | **HIGH**   | Logout tidak invalidate JWT — tidak ada token blacklist                             | `app/api/v1/auth.py` · `app/core/security.py`                                                                               | Token JWT tetap valid 24 jam setelah user logout. Token yang dicuri tidak bisa direvoke — breach tidak dapat dihentikan setelah logout.                                                 | Implementasikan token blacklist di Redis. Validasi token terhadap blacklist pada setiap request di `get_current_user`.                                                                      |
| 5   | **HIGH**   | JWT Token disimpan di localStorage browser                                          | Response body JSON → `localStorage` (frontend)                                                                              | Token accessible oleh JavaScript; serangan XSS dapat mencuri token secara langsung. Library pihak ketiga yang di-load di halaman bisa membaca token.                                    | Gunakan `HttpOnly Set-Cookie` untuk menyimpan token. Hapus token dari response body agar tidak pernah terekspos ke JavaScript.                                                              |
| 6   | **HIGH**   | DB Connection Pool Exhaustion — 3 koneksi per request                               | `app/core/security.py` · `get_current_user` · `_attach_roles_permissions_to_state` · `_attach_custodian_divisions_to_state` | Pool size hanya 15 koneksi total; 3 koneksi per request = maksimal 5 concurrent requests. Sistem menjadi timeout dan tidak responsif pada traffic normal.                               | Konsolidasikan 3 panggilan `session_scope()` menjadi 1 query gabungan. Reuse single session per request lifecycle.                                                                          |
| 7   | **HIGH**   | WebSocket `/ws/jobs/{job_id}` tidak memiliki autentikasi                            | `app/websockets/jobs.py` · endpoint `job_status_ws`                                                                         | Siapapun yang mengetahui `job_id` dapat mengakses hasil lengkap job (invoice OCR, bid analysis, ekstraksi kontrak) tanpa autentikasi apapun.                                            | Tambahkan JWT token validation sebelum `accept()`, seperti yang sudah ada di `chatbot_ws`. Verifikasi bahwa user yang request adalah pemilik job.                                           |
| 8   | **HIGH**   | Container berjalan sebagai root user                                                | `Dockerfile` · `Dockerfile.worker`                                                                                          | Jika terjadi RCE, attacker mendapat akses root penuh di dalam container. `scripts/` berisi admin tools, user management, dan seeding scripts ikut ter-bundle ke production image.       | Tambahkan `RUN groupadd --gid 1001 appgroup && useradd --uid 1001 ...` dan instruksi `USER appuser` sebelum `CMD`. Hapus `COPY scripts/` dari production Dockerfile.                        |
| 9   | **HIGH**   | GCS upload menggunakan `blob.public_url` — dokumen sensitif berpotensi terpublikasi | `app/core/storage.py` · method `upload()` dan `upload_bytes()`                                                              | Jika GCS bucket bersifat public, semua invoice, kontrak, proposal, dan hasil bid analysis dapat diakses oleh siapapun yang mengetahui URL-nya.                                          | Simpan hanya `blob_key` di database. Gunakan `signed_url_for()` untuk generate URL sementara dengan expiry saat file diakses. Verifikasi bucket tidak memiliki binding `allUsers`.          |
| 10  | **HIGH**   | Tidak ada startup validation untuk critical secrets                                 | `app/main.py` · `app/core/config.py` · fungsi `lifespan()`                                                                  | Aplikasi berjalan sukses dengan `JWT_SECRET_KEY=""`, `JWT_AUTH_ENABLED=False`, `DEBUG=True` tanpa peringatan. Deployment yang salah konfigurasi bisa berjalan di production.            | Tambahkan `_validate_production_config()` di `lifespan()` yang melempar `RuntimeError` jika secret kritis kosong atau konfigurasi development aktif di environment production/staging.      |
| 11  | **MEDIUM** | Auto-create user tanpa validasi domain email                                        | `app/api/v1/auth.py` · blok auto-create user di callback                                                                    | Guest atau kontraktor di Azure AD mendapat akses aplikasi secara otomatis tanpa persetujuan admin. Tidak ada audit trail siapa yang dibuat kapan.                                       | Tambahkan whitelist domain email yang diizinkan. Log setiap auto-create event ke audit trail. Implementasikan notifikasi ke admin untuk review.                                             |
| 12  | **MEDIUM** | JWKS Azure tidak di-cache                                                           | `app/core/security.py` · fungsi `get_azure_public_keys`                                                                     | Setiap proses login melakukan fetch JWKS dari Azure AD. Azure outage menyebabkan seluruh login gagal. Latency tambahan 200-500ms per login request.                                     | Cache JWKS di Redis dengan TTL 1 jam. Implementasikan fallback ke cached version jika fetch terbaru gagal.                                                                                  |
| 13  | **MEDIUM** | Tidak ada rate limiting di auth endpoints                                           | `app/api/v1/auth.py` · `/auth/token` · `/auth/get-azure-sso-url` · `/auth/callback`                                         | Brute force terhadap endpoint token dimungkinkan. State flooding dapat menghabiskan memory server. Endpoint rentan terhadap serangan DoS via spam request.                              | Implementasikan rate limiting menggunakan `slowapi`. Tambahkan account lockout setelah sejumlah percobaan gagal.                                                                            |
| 14  | **MEDIUM** | Auth events tidak tercatat di audit log                                             | `app/api/v1/auth.py` · `app/core/security.py`                                                                               | Tidak ada rekam jejak forensik untuk event login, logout, dan autentikasi gagal. Investigasi insiden keamanan menjadi tidak mungkin dilakukan.                                          | Panggil `UserActivityLogService.log_activity()` untuk semua auth events: login berhasil, login gagal, logout, dan auto-create user.                                                         |
| 15  | **MEDIUM** | `JWT_SECRET_KEY` default value string kosong                                        | `app/core/config.py` · field `jwt_secret_key`                                                                               | Jika `JWT_SECRET_KEY` tidak dikonfigurasi di environment, string kosong digunakan sebagai secret. Siapapun dapat memforging token yang valid.                                           | Hapus nilai default `""`. Tambahkan validator yang melempar error startup jika `JWT_SECRET_KEY` kosong di environment manapun.                                                              |
| 16  | **MEDIUM** | Celery worker berjalan dengan `--loglevel=DEBUG` di production                      | `Dockerfile.worker` · baris `CMD`                                                                                           | Full task arguments (termasuk isi file invoice, proposal), SQL queries, dan AI prompts/responses dari Gemini terdump ke production logs di Google Cloud Logging.                        | Tambahkan `ENV CELERY_LOG_LEVEL=INFO` di Dockerfile.worker dan gunakan `${CELERY_LOG_LEVEL}` di `CMD`. Default ke `WARNING` untuk production.                                               |
| 17  | **MEDIUM** | GCP Service Account key disimpan sebagai base64 di CI/CD variable                   | `azure-pipelines/dev.yml` · `pipeline-scripts/db-commands.sh` · Azure DevOps variable group                                 | SA key adalah long-lived credential. File `gcp-sa.json` tertinggal di disk build agent jika pipeline gagal sebelum langkah cleanup.                                                     | Migrasi ke Workload Identity Federation (tidak perlu key file). Atau tambahkan `trap cleanup EXIT` di shell script agar cleanup selalu berjalan.                                            |
| 18  | **MEDIUM** | Tidak ada validasi file type dan ukuran pada upload endpoint                        | `app/services/attachments_service.py` · method `create_attachment()`                                                        | Attacker dapat mengupload file tipe apapun (executable, HTML dengan XSS, SVG). Tidak ada batas ukuran file memungkinkan DoS via large file upload berulang.                             | Validasi MIME type di sisi server menggunakan `python-magic`. Batasi ukuran maksimum file (misal 50MB). Tolak tipe file yang tidak diizinkan sebelum menulis ke disk.                       |
| 19  | **MEDIUM** | Token JWT dikirim via query parameter di WebSocket                                  | `app/websockets/chatbot.py` · `app/websockets/po_query_chatbot.py`                                                          | Token tersimpan di server access logs, browser history, dan CDN/proxy logs. Siapapun dengan akses ke log server dapat mengambil token yang masih valid.                                 | Hapus fallback `websocket.query_params.get("token")` sepenuhnya. Wajibkan pengiriman token via `sec-websocket-protocol` header saja.                                                        |
| 20  | **MEDIUM** | Missing security response headers (CSP, HSTS, X-Frame-Options)                      | `app/core/middleware.py` · `app/main.py`                                                                                    | Tidak adanya CSP memungkinkan XSS via inline script. Tidak ada HSTS memungkinkan downgrade ke HTTP. Swagger UI dapat di-embed di iframe berbahaya (clickjacking).                       | Tambahkan `SecurityHeadersMiddleware` dengan header: `Content-Security-Policy`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Strict-Transport-Security`, `Referrer-Policy`. |
| 21  | **MEDIUM** | Verbose error messages mengekspos detail internal                                   | `app/api/v1/auth.py` · 4 lokasi penggunaan `str(e)` di `HTTPException.detail`                                               | `str(e)` dikembalikan langsung di API response — bocorkan nama library internal, URL service, dan timeout details yang memudahkan reconnaissance attacker.                              | Log exception secara internal dengan `logger.exception()`. Kembalikan pesan generic ke client: `"An authentication error occurred"`. Tambahkan global exception handler.                    |
| 22  | **MEDIUM** | `USE_MAILHOG=True` sebagai default — email tidak terkirim di production             | `app/core/config.py` · field `use_mailhog` · `app/core/email.py`                                                            | Jika `USE_MAILHOG=false` tidak di-set secara eksplisit, semua email (notifikasi kontrak, approval workflow) diarahkan ke MailHog yang tidak ada di production — gagal secara diam-diam. | Ubah default menjadi `use_mailhog: bool = Field(default=False, ...)`. Tambahkan guard di email service yang raise error jika MailHog diaktifkan di production.                              |
| 23  | **MEDIUM** | Database superuser (`postgres`) digunakan untuk application runtime                 | `env.example` · `pipeline-scripts/db-commands.sh`                                                                           | Jika credentials bocor atau terjadi SQL injection, attacker memiliki full database control: `DROP TABLE`, `COPY TO FILE`, bypass Row-Level Security, buat role baru.                    | Buat user `kpc_app_user` dengan hak DML saja (SELECT, INSERT, UPDATE, DELETE). Buat user `kpc_migrator` terpisah untuk DDL. Hapus akses superuser dari application runtime.                 |
